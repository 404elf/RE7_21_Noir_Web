# 给聊天 AI 的配置生成说明

玩家：将本文件上传或复制给聊天 AI，再说出你的需求，例如“节奏快一点、血量少一点，保留反制，不要强迫弃牌”。AI 只需要返回 JSON，不需要访问电脑或运行程序。

拿到结果后，复制纯 JSON，保存为 UTF-8 的 `我的玩法.json`，在网页版「游戏配置 → 导入配置 JSON」载入，检查后应用。不要把文件保存为 `.json.txt`。尚未应用的草稿不会影响房间；可选择服务器默认恢复规则。通过「AI 配置文件」按钮导出的说明会附上当前草稿作为模板。

---

## 以下内容供聊天 AI 使用

你要按玩家的需求生成 RE7 / 21 游戏预设。这是 21 点衍生对战：共享牌堆，数字 1–11 各一张；首牌隐藏；王牌可改变目标、赌注、牌面与防御。此配置对双方公平生效，不改变 AI 难度。描述的是相对权重，不是百分比。

**输出要求：只输出一个完整 JSON 对象，不要 Markdown 围栏、解释、注释、代码或省略号。顶层只包含 `game_settings` 和 `trump_weights`。保留下面模板中的全部键，数值必须有限，不能输出字符串形式的数字。未要求修改的项目保留模板值。**

默认目标固定 21、牌堆固定 1–11，除非玩家明确要求改变。相同数字不会重复。不要擅自改变这三个参数来制造难度。优先温和调整，避免所有功能牌权重为 0。不开启玩家未要求的高风险牌。不要写入计时、音效、网络、文件路径或测试结果；这些由游戏的独立设置管理。

实际起手数量为 `initial_trumps_count + round_reward_trumps_count`，不超过 `max_trumps_hand_size`；首次开局和再来一局使用同一规则。`number_card_draw_probability` 是纯数字王牌出现概率；其余概率按功能牌权重分配。纯数字王牌通过该概率管理，不要在 `trump_weights` 中添加 Two、Three 等纯数字键。权重 0 表示禁用，越大越常见；权重不必相加为 100。

## 对局参数

| JSON 键 | 含义 | 范围 |
| --- | --- | --- |
| `max_hp` | 最大生命值 | 1–999，整数 |
| `max_trumps_hand_size` | 手持王牌上限 | 1–100，整数 |
| `max_active_trumps_on_table` | 场上王牌上限 | 1–100，整数 |
| `target_score` | 默认目标点数 | 1–999，整数 |
| `initial_trumps_count` | 开局王牌数量（另加每局补充） | 0–100，整数 |
| `round_reward_trumps_count` | 每回合补充王牌 | 0–100，整数 |
| `hit_draw_trump_probability` | 抽牌时获得王牌概率（0–1） | 0–1 |
| `number_card_draw_probability` | 普通数字王牌概率（0–1） | 0–1 |
| `deck_range_start` | 牌堆最小点数 | 1–100，整数 |
| `deck_range_end` | 牌堆最大点数 | 1–100，整数 |

牌堆至少包含 4 个不同数字；建议维持 1–11。起手数量与每局补充数量应与手牌上限相称。

## 功能牌权重键

所有权重范围 0–10000，建议通常取 0–20。名称必须与下表完全一致，包括空格和加号。`Return+` 是配置名，游戏内对应归还加强牌（历史内部名 ADD2+）。

| 键 | 效果 |
| --- | --- |
| `Two+` | 获得 1 张王牌，并从牌堆中抽出数字 2。 |
| `Three+` | 获得 1 张王牌，并从牌堆中抽出数字 3。 |
| `Four+` | 获得 1 张王牌，并从牌堆中抽出数字 4。 |
| `Five+` | 获得 1 张王牌，并从牌堆中抽出数字 5。 |
| `Six+` | 获得 1 张王牌，并从牌堆中抽出数字 6。 |
| `Seven+` | 获得 1 张王牌，并从牌堆中抽出数字 7。 |
| `Add 1` | 此牌在场时，对手的赌注增加 1。 |
| `Add 2` | 此牌在场时，对手的赌注增加 2。 |
| `Shield` | 此牌在场时，你的赌注减少 1。 |
| `Shield+` | 此牌在场时，你的赌注减少 2。 |
| `Go 17` | 本局目标点数改为 17。 |
| `Go 24` | 本局目标点数改为 24。 |
| `Go 27` | 本局目标点数改为 27。 |
| `Destroy` | 移除对手场上最后打出的一张王牌。 |
| `Destroy+` | 移除对手所有场上王牌。 |
| `Destroy++` | 移除对手场上所有王牌。此牌在场时，对手不能使用王牌。 |
| `Return` | 将你最后抽到的一张明牌放回牌堆。 |
| `Return+` | 将对手最后一张明牌放回牌堆。此牌在场时，对手的赌注增加 2。 |
| `Remove` | 将对手最后抽到的一张明牌放回牌堆。 |
| `Perfect` | 抽出对你最有利的一张牌。没有安全的牌时，抽出点数最小的一张。 |
| `Perfect+` | 抽出对你最有利的一张牌。此牌在场时，对手的赌注增加 5。 |
| `Change` | 交换双方最后抽到的一张明牌。 |
| `Trump+` | 消耗此牌，再随机替换 2 张手中王牌，获得 3 张新王牌。 |
| `Trump++` | 消耗此牌，随机弃 1 张王牌，再获得 4 张王牌。 |
| `S-Attack` | 移除你场上的 3 张护盾。此牌在场时，对手的赌注增加 3。 |
| `S-Attack+` | 移除你场上的 2 张护盾。此牌在场时，对手的赌注增加 5。 |
| `Waste` | 对手使用 2 张王牌可解除；未解除则结算时失去一半王牌。 |
| `Waste+` | 对手使用 3 张王牌可解除；未解除则结算时失去全部王牌。 |
| `Desire` | 此牌在场时，对手的赌注增加其手中王牌数量的一半，向下取整。 |
| `Desire+` | 此牌在场时，对手的赌注增加其手中的王牌数量。 |
| `Love` | 让对手抽出最有利的一张牌。对手已爆牌或不能抽牌时无效。 |
| `Gamble` | 此牌在场时，双方赌注增加 100，对手不能抽牌。 |
| `D-Destroy` | 弃掉剩余王牌的一半并抽出对你最有利的一张牌。此牌在场时，对手的赌注增加 10。 |
| `Add 21` | 此牌在场且你恰好 21 点时，对手的赌注增加 21。 |
| `Happiness` | 双方各获得 1 张王牌。 |
| `Curse` | 随机弃 1 张剩余王牌，令未爆牌的对手抽牌堆中最大的牌。 |
| `M-Draw` | 获得 3 张王牌。此牌在场时，你的赌注增加 1。 |
| `Silence` | 此牌在场时，对手不能抽牌。 |
| `Oblivion` | 跳过本局结算，清空牌桌并重新发牌。 |
| `Harvest` | 使用王牌后获得 1 张王牌。 |
| `Escape` | 平局结束游戏，不扣血。 |
| `U-Draw` | 获得 2 张王牌，再抽出对你最有利的一张牌。 |
